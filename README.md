# India Village Analytics Dashboard

A full-stack Data Analytics Dashboard built using React.js, Node.js, Express.js, PostgreSQL, and Python.

## Features

- State, District, SubDistrict filtering
- Village search
- Dynamic dropdowns
- Analytics dashboard
- Village statistics visualization
- PostgreSQL database integration
- REST APIs
- Data import using Python

## Tech Stack

Frontend:
- React.js
- Bootstrap
- Recharts

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

Python:
- Pandas
- Psycopg2
